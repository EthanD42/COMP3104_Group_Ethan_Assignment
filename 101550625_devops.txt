COMP 2156 DevOps Course - Overview
COMP 2156 - DevOps Course Information

Course Overview:
COMP 2156 is a DevOps course offered at George Brown College as part
of the Computer Programming and related technology programs. The
course introduces students to the principles and practices of DevOps,
which combines software development (Dev) and IT operations (Ops).

Key Topics Covered:
- Version control systems (Git and GitHub)
- Continuous Integration and Continuous Deployment (CI/CD)
- Branching strategies and collaborative workflows
- Pull requests and code review processes
- GitHub Actions and automated workflows
- Infrastructure as Code (IaC) concepts
- Agile and DevOps methodologies

Learning Outcomes:
By the end of this course, students should be able to:
1. Use Git and GitHub for version control and collaboration
2. Set up and manage CI/CD pipelines using GitHub Actions
3. Apply branching strategies in a team environment
4. Resolve merge conflicts and manage pull requests
5. Understand the DevOps culture and its role in modern software teams

Course Format:
- Lectures and hands-on lab exercises
- Group assignments that simulate real-world DevOps workflows
- Individual and collaborative coding tasks
- Use of industry standard tools (Git, GitHub, CI/CD platforms)

Importance:
This course prepares students for careers in software development,
DevOps engineering, and cloud operations by providing practical
experience with tools and workflows used in the tech industry.
